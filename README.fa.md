# پنل ONEX v1.3.9

**پنل مدیریت پیکربندی VPN پیشرفته و توزیع خودکار**

یک پنل قدرتمند و مدرن برای مدیریت کانفیگ‌های VLESS، Trojan و سیستم سابسکریپشن با نظارت ترافیک، مدیریت کاربران و ربات تلگرام یکپارچه.

---

## ✨ ویژگی‌های اصلی

### مدیریت پایه‌ای
- 🔐 **پروتکل‌های متعدد**: VLESS، Trojan، Hysteria2، Tuic و غیره
- 📊 **آمار بلادرنگ**: نظارت ترافیک، تعداد اتصالات، مصرف پهنای باند
- 👥 **مدیریت کاربران**: ایجاد، ویرایش، حذف کانفیگ‌ها
- 🎛️ **فیلترهای پیشرفته**: دسته‌بندی بر اساس پروتکل، وضعیت، انقضا
- ⏱️ **مدیریت انقضا**: انقضای خودکار، محدودیت ترافیک و پهنای باند
- 🔄 **سیستم سابسکریپشن**: تولید URL‌های اشتراک خودکار

### داشبورد
- 🎨 **رابط مدرن**: طراحی Glass-morphism با انیمیشن‌های روان
- 🌙 **تم تاریک/روشن**: ۶ رنگ‌آمیزی از پیش تعریف‌شده
- 📱 **واکنش‌پذیر**: بهینه برای دسکتاپ، تبلت و موبایل
- 📈 **نمودارهای زنده**: ترافیک، آپتایم، متریک‌های اتصال
- 🔔 **اطلاعات بلادرنگ**: هشدارهای بروزرسانی

### امنیت و مدیریت
- 🛡️ **کنترل دسترسی**: سطوح اجازه‌های مختلف
- 🔑 **مدیریت جلسه**: احراز هویت مبتنی بر توکن
- 📝 **ثبت فعالیت**: ردپای کامل تمام اقدامات
- 🚀 **بروزرسانی یک‌کلیک**: استقرار خودکار روی Railway
- 📱 **ربات تلگرام**: مدیریت از طریق بات

### ویژگی‌های پیشرفته
- 🌐 **دسته‌بندی دامنه**: سازماندهی کانفیگ‌ها در گروه‌ها
- 📤 **عملیات دسته‌ای**: ایجاد/ویرایش/حذف چندگانه
- 🔍 **محدودیت IP**: تحدید اتصالات هم‌زمان
- 🚦 **محدودیت سرعت**: تنظیم پهنای باند
- 📅 **مدیریت خودکار**: غیرفعال‌کردن خودکار کانفیگ‌های منقضی
- 💾 **پشتیبان‌گیری**: تمام داده‌ها و تنظیمات

## 🚀 شروع سریع

### پیش‌نیازها
- **Python** 3.9+
- **pip** (مدیر بسته)
- **حساب Railway** (برای ابری) یا هر سرور

### نصب محلی

```bash
cd ONEX-main
pip install -r requirements.txt
python app.py
```

دسترسی در: `http://localhost:8000`
- **نام کاربری پیش‌فرض**: `admin`
- **رمز پیش‌فرض**: `admin`

⚠️ **فوری رمز را تغییر دهید!**

---

## ☁️ استقرار روی Railway (توصیه‌شده)

### مرحله ۱: آماده‌سازی
```bash
echo 'web: python app.py' > Procfile
```

### مرحله ۲: استقرار
1. وارد [railway.app](https://railway.app) شوید
2. **New Project** → **Deploy from GitHub**
3. انتخاب مخزن ONEX
4. Railway خودکار پایتون را نصب می‌کند
5. متغیرهای محیطی:
   ```
   PORT = 8000
   RAILWAY_VOLUME_MOUNT_PATH = /data
   ```

### مرحله ۳: ربات تلگرام
1. پیام [@BotFather](https://t.me/BotFather) بفرستید
2. ربات سازی و **توکن** را کپی کنید
3. در پنل → **ربات ONEX** → توکن را وارد کنید
4. **Webhook** را فعال کنید

## 📖 بخش‌های داشبورد

### ۱. **داشبورد**
خلاصه‌ای از:
- 📊 اتصالات فعال و ترافیک کل
- 📈 نمودارهای بلادرنگ
- ⏫ آپتایم سرور
- 📱 فعالیت‌های اخیر

### ۲. **کانفیگ‌ها**
ایجاد و مدیریت:
- **نام**: شناسه منحصر
- **پروتکل**: انتخاز پروتکل
- **محدودیت ترافیک**: GB/TB (۰ = نامحدود)
- **انقضا**: روز (۰ = بی‌نهایت)
- **محدودیت IP**: تعداد IP‌های هم‌زمان
- **محدودیت سرعت**: Mbps

### ۳. **گروه‌ها**
سازماندهی در گروه‌های اشتراک:
- چند کانفیگ در یک URL
- QR کد قابل اشتراک
- آمار سطح گروه

### ۴. **آمار**
تحلیل زمانی:
- مصرف روزانه/هفتگی/ماهانه
- تعداد اتصالات فعال
- توزیع پروتکل‌ها

### ۵. **لاگ فعالیت**
ردپای کامل:
- چه کسی اقدام کرد
- زمان اقدام
- خطاها و هشدارها

### ۶. **ربات ONEX**
مدیریت از تلگرام:
- لیست کاربران
- ارسال پیام دسته‌ای
- تنظیمات

### ۷. **تم و ظاهر**
سفارشی‌سازی:
- ۶ رنگ‌آمیزی از پیش تعریف‌شده
- رنگ سفارشی
- تاریک/روشن
- فارسی/انگلیسی

### ۸. **تنظیمات**
مدیریت:
- تغییر رمز
- پشتیبان‌گیری و بازیابی
- امنیت و جلسات

## 📋 پارامترهای کانفیگ

### محدودیت ترافیک
```
۰ = نامحدود
۱ = ۱ GB
۱۰۰ = ۱۰۰ GB
۱۰۰۰ = ۱ TB
```

### محدودیت سرعت
```
۰ = نامحدود
۱ = ۱ Mbps
۱۰۰ = ۱۰۰ Mbps
۱۰۰۰ = ۱ Gbps
```

### انقضا
```
۰ = بی‌نهایت
۱ = ۱ روز
۳۰ = ۳۰ روز
۳۶۵ = ۱ سال
```

### محدودیت IP
```
۰ = نامحدود
۱ = فقط ۱ IP
۵ = تا ۵ IP متفاوت
```
